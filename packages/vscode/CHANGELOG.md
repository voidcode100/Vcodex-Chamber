# Vcodex-Chamber changelog

## 1.0.0 — 2026-10-06

First Vcodex-Chamber release, adapted from OpenChamber's MIT-licensed UI.

- Codex app-server sessions, streaming, permissions, fast mode and read-only ownership handling.
- WinUI 3 WindowsSender with queued screenshots, paired TLS transport, keyboard/mouse hotkeys, push-to-talk and background operation.
- Client microphone dictation through Codex Audio and Codex sign-in, with an optional compatible transcription endpoint.
- Current-turn Markdown teleprompter with looping scroll, pause and Ctrl+wheel font scaling.
- Shared session routing, session prompts, queue removal, retries and duplicate-request protection.
- Removed temporary persistent diagnostics and the old WinForms client; centralized build outputs.

This project has its own SemVer series. Earlier OpenChamber versions and local development builds are not Vcodex-Chamber releases. See the repository's OPENCHAMBER_SYNC.md for provenance and compatibility notes.
