# Vcodex-Chamber v1.0.0

基于 OpenChamber 界面适配 Codex app-server 的首个独立版本，同时发布 VS Code 扩展和 WinUI 3 WindowsSender。

## 本版功能

- Codex 会话、历史读取、流式回复、权限、fast 模式、命令/修改展示和占用时只读提示。
- WindowsSender 多图截图队列、独立发送、逐张删除/清空、失败重试和 TLS 配对。
- 自定义键盘及鼠标热键、专用按住说话、托盘后台和 `--headless` 启动。
- 客户端麦克风听写：停止后转写并自动发送；远程 WindowsSender 发送录音控制，声音在 VS Code 主机采集。
- 当前轮 Markdown 提词器、输出完成后循环滚动、暂停和 Ctrl+滚轮缩放。
- 移除临时诊断日志及旧 WinForms 架构，统一版本和构建产物。

## 下载和安装

- **Vcodex-Chamber-1.0.0.vsix**：Windows x64 扩展，包含 Codex CLI。VS Code 选择“从 VSIX 安装”。替换旧的 2.x 开发版时，可执行 `code --install-extension Vcodex-Chamber-1.0.0.vsix --force`，随后重新加载。
- **Vcodex-Chamber-WindowsSender-1.0.0-win-x64.zip**：解压后运行 `WindowsSender.WinUI.exe`，必须保留整个目录。包含 .NET 和 Windows App SDK 运行文件。
- **SHA256SUMS.txt**：下载文件的 SHA-256 校验值。

请在客户端设置中开启 WindowsSender 接收端，并在发送端填写客户端地址、端口、配对令牌及证书指纹。语音需要启用官方 `openai.codex-audio` 扩展；默认复用 Codex 的 ChatGPT 登录，内部转写服务受账号/网络条件影响，也可配置兼容转写服务。

扩展内部 ID 保留 `fedaykindev.openchamber`，沿用已有设置与会话存储。项目独立于 OpenAI 和 OpenChamber 官方发行。许可证、来源及详细使用说明见仓库 README。
